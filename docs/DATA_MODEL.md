# Модель данных

| Сущность | Ключевые данные |
|---|---|
| own_product | Кабинет, seller product_id, offer_id, подтверждённая связь с публичной карточкой, активность |
| marketplace_card | Публичный ID Ozon как bigint, канонический URL, продавец, модель, толщина, размеры и количество |
| comparison_link | Наш товар, карточка конкурента, состояние, автор и доказательство сопоставимости; уникальная активная пара |
| collection_job | Карточка, регион, слот UTC, состояние, аренда, дедлайн; уникальный ключ карточка + регион + слот |
| collection_attempt | Задание, время начала и конца, версия адаптера, исход, класс ошибки |
| observation | Попытка, фактический ID, UTC-время, доступность, наблюдаемый регион, доказательство, версия схемы, ограниченная ссылка на артефакт |
| observed_price | Наблюдение, тип regular/card/seller, сумма numeric(14,2), валюта, собственное время получения, состояние и источник поля; уникальность снимок + тип |
| manual_review | Снимок или поле, проверяющий, время, вердикт и контрольные значения |
| strategy_revision | Наш товар, стратегия, выбранный конкурент, тип сигнала, параметры, версия и автор |
| floor_revision | Наш товар, МРЦ в RUB, период действия, автор и время |
| price_decision | Версии настроек, ID снимков, старая и предлагаемая цена, основания, исход, режим |
| price_write | Решение, уникальный ключ отправки, попытки и статусы API, подтверждение чтением |

Хранить деньги десятичными значениями, применять проверки положительности и валюты. Для missing, ambiguous, unavailable и error сумма пуста. Хранить время в UTC, отображать в Europe/Moscow. Идентификатор карточки из URL требует явного сопоставления с SKU, offer_id и seller product_id. История добавляется новыми записями, ручная сверка хранится отдельно. Артефакты без секретов имеют ограниченный срок хранения.
