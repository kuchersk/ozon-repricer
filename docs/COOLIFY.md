# Развёртывание наблюдения в Coolify

Создайте отдельное приложение из репозитория `kuchersk/ozon-repricer`. Выберите сборку **Dockerfile**, базовую папку `/`, Dockerfile `/Dockerfile`, внутренний порт **8765**. Приложение слушает этот порт внутри контейнера. Доступ извне через прокси Coolify по отдельному HTTPS-домену. Host port mapping не требуется.

## Конфигурация

1. Добавьте отдельный HTTPS-домен и укажите тот же адрес в `OZON_OBSERVER_ORIGIN` без завершающей косой черты.
2. В **Persistent Storage** создайте постоянный том с путём внутри контейнера `/data`. Используйте одну реплику. Если используется каталог хоста, выдайте право записи пользователю контейнера UID 1000. Контейнер завершится при запуске, если каталог недоступен для записи.
3. Добавьте переменные ниже как **runtime**. Секреты храните в Coolify, отдельный Seller API ключ должен иметь право только на чтение. Данные в колонке «Пример» демонстрационные.

| Переменная | Назначение | Пример |
|---|---|---|
| `OZON_OBSERVER_ORIGIN` | Публичный адрес HTTPS | `https://repricer.example.com` |
| `OZON_DASHBOARD_USER` | Логин панели | `observer` |
| `OZON_DASHBOARD_PASSWORD` | Уникальный случайный пароль от 24 символов ASCII без пробелов | Задать в Coolify |
| `OZON_INGEST_TOKEN` | Независимый случайный токен от 32 символов, буквы, цифры, дефис и подчёркивание | Задать в Coolify |
| `OZON_PRODUCT_JSON` | JSON с Product ID, артикулом продавца и порогами из прайса | См. `app/product.example.json`, вставить одной строкой |
| `OZON_OBSERVER_CLIENT_ID` | Client ID кабинета продавца | Задать в Coolify |
| `OZON_OBSERVER_READ_KEY` | Seller API ключ на чтение | Задать в Coolify |

В режиме `hosted` запись цен по умолчанию отключена. При выделении ресурсов начните с 0,5 vCPU и 256 МБ RAM и сверяйте показатели VPS. Readiness проверяется через `GET /health`. После деплоя убедитесь, что HTTPS работает и панель запрашивает логин. История, параметры dry-run и журналы сохраняются в `/data`. Настройте резервное копирование тома и проверку восстановления отдельно от Repairkit.

## Подключение Chrome

1. Обновите расширение из папки `extension` на месте и нажмите «Перезагрузить» в списке расширений.
2. Откройте «Параметры» расширения. Введите тот же HTTPS-адрес и токен приёма замеров. При сохранении разрешите доступ к указанному домену.
3. Откройте карточку М3 с московским ПВЗ и нажмите «Считать цену». Сверьте новую запись в панели со строкой «С другими банками» на карточке.
4. Выполните dry-run и проверьте, что отображается предельная цена из кабинета. Перезапустите приложение и убедитесь, что история сохранилась.

Для остановки используйте кнопку «Остановить» в расширении и выключите отдельное приложение в Coolify. Тестовая процедура не запускает ресурсы Repairkit.

## Одна подтверждаемая запись М3

1. Для отдельной согласованной пробы добавьте в Production две переменные только для Runtime. Установите `OZON_ENABLE_TRIAL_WRITE=1` и задайте отдельный ключ с правом изменения цен в `OZON_OBSERVER_WRITE_KEY`. Вводите ключ через защищённый доступ к Coolify. Переразверните приложение.
2. Отправьте свежий замер для Москвы и нажмите «Проверить решение». Dry-run показывает предложение, если его допускают настройки. Для записи замер должен быть не старше десяти минут.
3. Нажмите «Применить пробное предложение» только если согласны с указанной суммой для М3. Сервер сверяет замер, настройки и оба текущих значения, отправляет одинаковую сумму в предельную цену и ограничение для акций и проверяет результат через Seller API.
4. Отправьте новый замер витрины. После теста удалите обе переменные записи и переразверните приложение. Журнал попытки хранится в `/data/price-writes.jsonl` и блокирует повторную отправку даже после перезапуска. При неопределённом результате сверьте оба поля в кабинете Ozon Seller.

При включении режима сохраняется вход в панель и проверка источника запроса. Замеры из Chrome сами по себе запись цены не запускают.
