# Развёртывание

Целевой сервер Selectel с Ubuntu 24.04, 2 vCPU, 4 ГБ RAM и 50 ГБ SSD. Действие после разрешения владельца. В Coolify создать отдельный Compose-проект, приватную сеть, том PostgreSQL и секреты. Через reverse proxy публиковать только кабинет/API после настройки TLS и входа. Использовать отдельный идентификатор проекта для операций остановки и удаления.

До запуска снять базовые показатели свободной памяти, CPU, диска и Repairkit. Стартовое предложение для проверки ёмкости — PostgreSQL 384 МиБ, API 192 МиБ, worker HTTP 256 МиБ либо Chromium 768 МиБ, worker до 0,5 vCPU и одна активная задача. Проверить фактическое применение лимитов и запас хоста. При недостатке памяти отложить запуск браузера на VPS. Настроить ограничение журналов и очистку временных файлов.

Ежедневный pg_dump хранить зашифрованным с ограниченным доступом. Предлагаемая ретенция 14 ежедневных копий в пределах согласованного бюджета. По возможности использовать отдельное место хранения; копия на том же VPS не защищает от потери сервера. До пилота выполнить восстановление в отдельную БД, проверить последние снимки, связи и историю цен, зафиксировать длительность и отставание. Предлагаемые цели RPO до 24 ч и RTO до 4 ч.

Перед обновлением сделать копию, сохранить версию образа и проверить миграцию на тестовой БД. При деградации остановить worker, при необходимости вернуть предыдущий образ с совместимой схемой или восстановить отдельную БД и сверить данные. Контролировать пропущенные слоты, дисковое место, возраст копии и 5xx.
