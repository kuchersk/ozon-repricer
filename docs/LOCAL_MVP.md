# Локальный MVP

Приложение наблюдает серую и зелёную цены Шумофф М3, 16 листов, SKU 275647765. Расширение Chrome с московским ПВЗ отправляет свежие замеры на локальный сайт. Seller API используется для чтения предельной цены и для одной явно подтверждённой пробной записи.

## Запуск на Windows

1. Нужен Node.js 20 или новее. Приложение использует только стандартную библиотеку Node.js.
2. Скопируйте `app/product.example.json` в `app/product.local.json`. Подставьте Product ID и артикул продавца своего М3, ориентир серой цены и нижний порог зелёной.
3. Запустите `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Start-OzonObserver.ps1` из корня репозитория. Введите Client ID и ключ на чтение. Для запуска без Seller API можно использовать `node app/server.cjs` после создания конфигурации.
4. Откройте `http://127.0.0.1:8765`. Установите распакованное расширение из папки `extension` через `chrome://extensions`.
5. На карточке М3 выберите московский ПВЗ. В расширении нажмите «Считать цену» и проверьте, что замер появился на сайте. Доступны разовый автозамер и расписание на три часа при открытом Chrome.

В dry-run задайте минимальную предельную цену, шаг, паузу после записи и число изменений за 24 часа. Приложение проверит последний замер и текущую цену продавца. Допустимое предложение появится в журнале.

## Одноразовая запись

Обычный запуск работает в режиме наблюдения. Для отдельной согласованной пробы можно добавить `-EnableTrialWrite` к команде запуска и ввести отдельный ключ на запись. Перед нажатием кнопки отправьте свежий замер и выполните dry-run. Сайт проверит, что замер, настройки и текущие значения совпадают с предложением, передаст одну сумму в предельную цену и порог акций и перечитает оба поля. После одной попытки дальнейшие отправки заблокированы. При неподтверждённом результате проверьте оба поля в Ozon Seller.

Ключи вводятся локально. История, настройки и журналы хранятся рядом с `server.cjs` и исключены из Git. При переносе предыдущей локальной установки сохраните эти файлы. Чтобы учесть старую пробную запись, её журнал можно скопировать в `app/trial-write.local.jsonl`.

Сервер слушает только `127.0.0.1`. Перед развёртыванием в Coolify нужны отдельная настройка доступа к HTTPS, аутентификация источника замеров и постоянное хранилище. Текущая сборка рассчитана на локальный запуск.
