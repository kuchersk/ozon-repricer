# Ozon Parser & Repricer

Самостоятельный сервис мониторинга московских покупательских цен на Шумофф. Первый результат — проверенный сбор обычной цены и цены с Ozon Картой. Репрайсинг рассматривается после пилота и отдельных испытаний.

Локальный MVP проверен на Шумофф М3: расширение Chrome передаёт замеры сайту, сайт сравнивает серую цену с прайсом и поддерживает одну подтверждаемую запись через Seller API.
