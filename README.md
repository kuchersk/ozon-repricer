# Ozon Parser & Repricer

Сервис мониторинга покупательских цен и управления предельными ценами товаров Ozon. Главная страница содержит каталог с поиском, чтением цен Seller API и ручным изменением цены выбранного SKU после подтверждения.

Мониторинг витрины через расширение Chrome и автоматическая проверка решения проверены на Шумофф М3; панель доступна по `/m3`. Массовый сбор покупательских цен остальных SKU остаётся следующим этапом. При записи из каталога новая предельная цена дублируется в ограничение акций; результат проверяется чтением обоих полей.
